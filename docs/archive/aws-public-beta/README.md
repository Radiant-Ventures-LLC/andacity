# Archived: AWS public-beta launch reports (CLAUDE-UI-030 → 050)

These reports cover the June 2026 attempt to launch a public beta on AWS EC2/RDS. That attempt stopped at external operator gates, and the infrastructure has since been retired: the RDS host no longer resolves, and the EC2 deploy workflows were removed in 0.7.0.

They're kept for history only. Hosts, env vars, checklists and "launch authorized" statements in these files don't describe the current environment. For current status and plans, see [`docs/ROADMAP.md`](../../ROADMAP.md). For the dev environment, see `deploy/dev/`.
